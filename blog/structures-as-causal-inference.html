Every Structure of the World Is a Causal Inference

A walk through how PSI turns the classical primitives of vision — flow, segments, depth — into counterfactual queries on a single probabilistic world model.

The central claim of PSI is simple, but it takes some unpacking: every meaningful structure of the visual world can be written as a causal inference on a correctly formulated world model. You do not need a separate network for optical flow, another for segments, another for depth. If the model of the joint distribution over the world is sharp enough, those structures are already latent inside it. The job is to ask the right counterfactual question.

1. Properties are not labels. They are interventions.

A world model Ψ places a distribution over what could happen next given what has happened so far. Once you have that distribution, you can ask two kinds of questions:

  • Factual: given these frames, what do I expect to see next?
  • Counterfactual: if I changed one thing about the past, what would the model now expect?

A visual property — motion, shape, distance — is always a statement about how the world would respond to some hypothetical. Motion is what happens to appearance across time. Object identity is what moves together under force. Depth is how disparity scales with viewpoint. These are interventional descriptions. They are not features of a single image; they are features of a pair: what I see and what would happen if.

PSI's Section 3 formalizes this as a chain of equalities:

Properties of interest = intermediate structures = structured prompts comparing factual and counterfactual predictions from Ψ = causal inferences from Ψ = generators of new token types.

The rest of the section puts three of the most-studied visual structures — flow, segments, depth — through this pipeline.

2. Optical flow as a tracer experiment

Optical flow is, definitionally, the causal effect of appearance on future position. So we write it as an intervention. Take frame f₀, drop a small Gaussian bump on patch i, and ask: how did the predictive distribution over f₁ change? Formally,

j*(i) = arg maxj KL( Ψ[ f̃₀(i), f₁ℛ ] ∥ Ψ[ f₀, f₁ℛ ] ).

Wherever the distribution moves the most is where the tracer went. The displacement from i to j*(i) is the flow vector at that patch. This only works if the predictor is genuinely distributional — a regression model would wash out multimodal flow (a windblown leaf that could go either way) into the mean and destroy the signal.

3. Object segments as hypothetical motion

A Spelke object, in the developmental-psychology sense used here, is a set of pixels that move together under force. That is a hypothetical statement: if I pushed this pixel, which others would come along? Turning that into a prompt on Ψ is straightforward. Copy a patch from f₀, paste it into f₁ displaced by some hypothetical motion, and let the model fill in the rest of f₁.

Because Ψ is a trained predictor of consistent scenes, it will complete f₁ by also moving the rest of the object. Running the flow extractor from Section 3.2 between f₀ and this hallucinated f₁ lights up exactly the patches that moved coherently with the seed. Sweep the seed across the image and you get instance segmentation, entirely without class labels.

This is where the multimodality of Ψ really matters again. A non-rigid object — a hand, a cloth — can deform in many plausible ways under the same hypothetical push. A deterministic model would average them out. Ψ samples a coherent completion.

4. Depth as a viewpoint counterfactual

Depth is what happens to apparent position as the camera moves. Again, that's a counterfactual: if I shifted the camera by b, where would each pixel land? PSI makes this literal. Append a Campose token describing a small baseline translation, sample the resulting frame from Ψ, and compute flow between the two. The flow magnitude at each pixel, divided by the baseline, is disparity — and therefore depth — with no stereo rig and no depth labels.

5. Why this composes into a bigger loop

Each of these extraction programs is a short prompt — not a new network, not a new loss — whose outputs have the structure of a dense map over the scene. PSI then treats those maps as new token types: they can be serialized back into the model as discrete handles alongside RGB. A flow token can be conditioned on, a depth token can be produced, a segment token can be edited by a user.

Once a structure is a token, it is subject to the same interventional grammar as everything else. You can run counterfactuals on it. You can train against it. You can combine it with others. This is the mechanism that lets the three-step cycle on the landing page actually close.

6. What this essay is really arguing

The slogan form of all this:

If your predictive model of the world is good enough, you do not need to design perception modules. The classical primitives of vision are already latent in it, waiting to be unlocked by the right counterfactual prompt.

The converse is the more demanding claim, and the more interesting one: if a structure of the world cannot be written this way, it is probably a sign that your model is missing an axis of variation it should have. The structure extraction pipeline is therefore not just a way to get flow or depth. It is a diagnostic for whether the world model is correctly formulated at all.
