# PsiBorg capability film

The public page uses the reviewed Remotion composition in FullFilm.jsx: 5548 frames at 30 fps, presented at 1.2× speed (154.11 seconds), 1280×720. The interactive player is player.jsx. Install the dependencies from package.json, then run `node build.mjs` here to rebuild ../hero.js.

The animation uses relative assets/capability-film paths for the /psi-website/psibot/ URL. Preserve recorded media, goal images, prediction values, timing, dark/light palettes, and final-frame comparison holds when editing. The page supports muted autoplay and looping, click/tap or Space/Enter to pause/resume, draggable seeking, and chapter navigation.

The opening reveals all nine input/output paths in a fixed randomized order over 45 frames (1.25 seconds at the player speed), then preserves the prior 165-frame complete-figure hold and 15-frame focus. Grid playback starts together at opening frame 300; the final overview is frame 434.
